# PGM 开发测试

PGM 支持通过 `tools/build.py --pgm` 显式启用，当前仍是开发测试功能，未包含在 v0.1.2 Release 中。

使用固定依赖和原有 408 MHz / A68K 组合构建：

```powershell
python -X utf8 tools/build_pgm.py --toolchain "你的工具链/bin" --host-cc "你的gcc.exe"
```

输出 `dist/H1ArcadePGM.bda` 和对应构建记录。它也保留原有 Neo Geo 支持。

首批目标是《三国战纪》一代 `kov` V117。其他 PGM 游戏、改版以及 PGM2/PGM3 尚不支持；不能只重命名 ZIP 来变成受支持版本。

将自己提供的 `kov.zip` 和 `pgm.zip` 放在 H1 的 `A:\ARCADE`，打开带 PGM 支持的街机应用选择游戏 ZIP。首次在设备上生成同目录 `.h1pgm` 文件，后续复用缓存。若 A 盘写缓存失败且临时文件已成功清理，会尝试建立 `B:\ARCADE` 并把缓存写入 B 盘；下次仍选择原 ZIP 即可复用它。原 ZIP 保留。已有缓存或临时文件不会被覆盖。

缓存约 64.2 MiB，包括原始程序、图形、声音及每个 4 KiB 页的 CRC。转换按块解压、验证成员 CRC，写完后读回检查数据和页校验表，再以同目录改名提交。转换失败或取消会清理本次临时文件。

68000 复用 A68K；PGM 内存总线单独处理，不使用 Neo Geo 的 RAM/ROM 快速映射及轮询 HLE。Z80 复用现有解释器，端口改接 ICS2115。KOV ASIC28 使用上游 HLE；程序解密从固定 FBA 源码生成，未更改上游 checkout。

图形与声音 ROM 按需读取，运行时用 2 MiB 的四路页缓存，命中前核对页标签，读取新页时核对 CRC。背景 5-bit 像素按行解码，文字层使用 4-bit，精灵使用掩码及三像素打包颜色。背景整行取数，精灵用连续读游标并检查其缓存标签，避免另一条流换页后误用旧指针；完全不可见的精灵不绘制。独立处理图层优先级、翻转、缩放与行滚动。不会分配上游完整展开后的大型图形区。

声音合成降为 8 kHz，并按真实时长调整振荡器步进；设备音频输出沿用原有重采样路径。默认音量 10%。显示使用原始 448×224、4:3 或全屏；暂停菜单和按键设置沿用原有界面。

`tests/pgm_import_host.py` 仅验证生成的非游戏数据和文件转换，不运行游戏 CPU。能否启动、画面、输入和速度以 H1Debug 真实 H1 的记录为准。

## 2026-10-21 真机结果

用户自备的 `kov` V117 已通过真实 H1 启动、投币、开始、进入第一关“截江救阿斗”、移动与攻击、触屏暂停/继续/退出。原始 448×224 与 4:3 显示、PGM/ICS2115 关于页面已检查。测试音量 10%，退出恢复原始 336 MHz，H1Debug 保持运行。

首次转换在 A 盘写入失败后回退 B 盘，包含完整读回校验共 14,858 个 40 Hz tick，约 371.45 秒；生成 67,305,856 字节缓存。再次选原 ZIP 直接复用缓存。全部页 CRC 表和各区头与 PC 参考一致，额外抽样 145,792 字节；未通过 USB 下载整份缓存重新计算 SHA256。

在 408 MHz、4:3、跳1帧、8 kHz 合成下，第一关的一个 19.95 秒战斗窗口记录 226 个逻辑帧、113 个显示帧，即 **11.33 / 5.66 FPS**。最初逐像素查缓存的版本在另一个第一关窗口为 7.94 / 3.97 FPS；两次不是相同状态的确定性重放。当前仍明显卡顿，声音有断续，尚不适合正常速度游玩。

保留的原绘图实现可通过 `h1_pgm_draw_probe` 在本应用暂停菜单中进行冻结帧对照。已记录开场、关卡过渡和两张战斗帧，整张 448×224 画面像素差异均为 0。计时粒度为 25 ms；其中一张战斗帧原路径 7 tick、优化路径 4 tick。此结果不等同于全游戏满速或所有缩放组合均已验证。

同一份 BDA 已覆盖安装到原街机应用位置，并用现有《拳皇97》缓存回归。在未暂停的 10.025 秒演示流程窗口中，记录约 59.15 逻辑帧/秒、29.53 显示帧/秒；这不是完整战斗或全游戏性能保证。最终正常返回桌面，恢复 336 MHz，按键和触屏均已释放，H1Debug 服务保持运行。

源 ZIP 的 H1 副本曾有一个字节拷贝错误。电脑原文件全成员校验通过；核对 H1 整份文件 CRC 后，仅按已确认的原字节修复，并重新核对整份 ZIP 的 CRC。游戏和 BIOS 字节不随仓库分发。
